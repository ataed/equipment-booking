# Stories

## Trainer

- As a trainer, I want to see all available equipment, so that I know what I can book without asking the manager.
- As a trainer, I want to book equipment by choosing a date and time, so that I don't have to ask in WhatsApp.
- As a trainer, I want to see my own bookings, so that I don't search WhatsApp history.
- As a trainer, I want to cancel my booking, so that I don't have to do it through WhatsApp or ask the manager.
- As a trainer, I want to be notified when my booking is approved, so that I don't have to ask the manager to check his notebook.

## Manager

- As a manager, I want to see all bookings, so that I don't have to look through WhatsApp messages.
- As a manager, I want to approve or refuse a trainer's booking, so that I don't have to tell them in WhatsApp.
- As a manager, I want to see who has which equipment right now, so that I know what's unavailable and what hasn't been returned.
- As a manager, I want to receive a notification for an urgent booking, so that I can decide on it quickly.
- As a manager, I want to list or remove equipment, so that unavailable equipment isn't requested.
- As a manager, I want to mark equipment returned, so that equipment can be booked by others. If the trainer attached a damage photo, I check it and mark the equipment out of service.
- As a manager, I want to create trainer accounts, so that no one unknown can create an account and book equipment.
- As a manager, I want pending bookings to be automatically refused 30 minutes before their start time or after 24 hours pending (whichever comes first), so that equipment isn't stuck unavailable because nobody looked at the request in time.
- As a manager, I want to mark equipment out-of-service, so that a trainer can't book it when it's unavailable.
