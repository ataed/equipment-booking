# Stories

16 stories. Sprint assignment and ordering come from backlog-passes.md.

## Sprint 0

Capability delivered by the seed script. The screens for doing it in the app
are Sprint 2 stories.

- As a manager, I want to create trainer accounts, so that no one unknown can
  create an account and book equipment.
- As a manager, I want to list or remove equipment, so that unavailable equipment
  isn't requested.

## Sprint 1, core loop

- As a trainer or manager, I want to sign in and land on my own screen, so that I
  only see what my role allows.
- As a trainer, I want to see all available equipment, so that I know what I can
  book without asking the manager.
- As a trainer, I want to book equipment by choosing a date and time, so that I
  don't have to ask in WhatsApp.
- As a trainer, I want to see my own bookings, so that I don't search WhatsApp
  history.
- As a manager, I want to approve or refuse a trainer's booking, so that I don't
  have to tell them in WhatsApp.

## Sprint 2, lifecycle

Ordered by value. Cut order is this list read from the bottom up.

- As a trainer, I want a push notification when my booking is decided, so that I
  don't have to open the app to check.
- As a manager, I want to mark equipment returned, so that it can be booked by
  others.
- As a trainer, I want to attach a photo when equipment comes back damaged, so that
  the manager knows before someone else books it.
- As a manager, I want to take a damaged device out of service, so that it can't be
  booked until it's repaired.
- As a manager, I want to see who has which equipment right now, so that I know
  what's unavailable and what hasn't been returned.
- As a trainer, I want to cancel my booking, so that I don't have to do it through
  WhatsApp or ask the manager.
- As a manager, I want to receive a notification for an urgent booking, so that I
  can decide on it quickly.
- As a manager, I want to see all bookings, so that I don't have to look through
  WhatsApp messages.
- As a manager, I want pending bookings to be automatically refused 30 minutes
  before their start time or after 24 hours pending (whichever comes first), so
  that equipment isn't stuck unavailable because nobody looked at the request in
  time.
